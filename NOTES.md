# NOTES.md — teaching preferences

- Workflow is **Predict → Observe → Explain**: every lesson should end by pointing at a lab experiment the user must first write a prediction for. Never run the experiment for them.
- Lessons feed public blog episodes (`blog/NNNN-*.md`). Prefer examples that produce transcript-worthy output.
- Time budget is 3–6 hrs/week: keep lessons completable in one sitting (~10–15 min).
- The user likes concise, CLI-style communication in chat; rich detail belongs in lessons and posts, not in chat.
- Quiz answers must be exactly equal length — never leak the answer through formatting.
- English is the working language; keep sentences simple, avoid idioms in lessons.
- Episode ↔ lesson mapping: each episode (1–5) starts with a lesson; learning-records are written after the experiment, when there is evidence of understanding.
- Glossary is currently empty by policy: terms get added only after the user has used them correctly.
